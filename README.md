# CWG AI Website

AI-powered lead capture and order assistant for Custom Werks Graphics.

## Features

- Professional hero section showcasing CWG services
- AI chatbot for capturing lead information
- Service grid highlighting 12 ways CWG helps customers
- "How It Works" process walkthrough
- Sales inbox preview with realistic examples
- Ideas mode for helping customers explore products
- Fully responsive design (mobile, tablet, desktop)

## Deployment

This site is deployed to Vercel and automatically updates when changes are pushed to the main branch.

### Local Development

```bash
npm install
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Deploy

```bash
git push origin main
```

Vercel will automatically build and deploy.
